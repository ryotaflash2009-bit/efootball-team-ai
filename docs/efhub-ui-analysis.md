# eFHUB UI 分析（スクリーンショット11枚）

作成日: 2026-08-28
対象: `./screenshots/` 内の画像11枚（読み取りのみ。変更・移動・改名は行っていない）

> 用語について: このドキュメントでは専門用語に短い説明を付けています。
> 例）OVR = 選手の総合能力値 / ドロップダウン = クリックで下に開くメニュー。

---

## 0. 分析の前提

- eFHUB は日本語 UI と英語 UI を持つ（同じ画面が両言語で確認できた）。
- 配色は「ほぼ黒の背景 + 蛍光イエロー(ライムグリーン)のアクセント」。
- 情報密度が高く、縦スクロール・横スクロール前提のレイアウト。
- 未ログインでも閲覧でき、保存・投稿系の操作にサインイン導線が常時表示される。

## 2. グローバルナビゲーション（全画面共通）

事実（画像で確認）:

- 上部固定ヘッダー。左にロゴ（「27」+ eFHUB）。
- メニュー項目: **プレイヤー▼ / マネージャー / コミュニティ▼ / ティアリスト / eFHUB League**
  - ▼ = ドロップダウン（クリックで下にサブメニューが開く）
- 中央〜右に検索バー「選手・マネージャーを検索...」
- 右側: 言語切替（地球アイコン）、アプリDLアイコン（Apple / Google Play）、**Get Pro**（有料プラン）、**サインイン**

推測:

- 「プレイヤー▼」の中に 一覧 / 比較 などのサブページ、「コミュニティ▼」の中に フィード / スカッド共有 などがある。

## 3. ホーム画面

事実:

- 「eFHUB」ロゴ + 大きな検索バーのヒーロー領域。
- パックごとの横スクロール行（カルーセル）。各行の見出しは `パック名 + 日付`（例: `Summer Transfer 27 Aug '26`、`POTW 27 Aug '26`、`Japanese Stars 31 Aug '26`）。
- 各カード: 左上に大きく **OVR**、その下に **ポジション略号**（CF, DMF, RWF, CB, LB, GK など）、クラブ/国旗バッジ、下部に **選手名**、★（1〜5、カードのレア度）、下部にブースターアイコン。
- カード画像下部にリンク `https://efhub.com/players/{数字ID}` が確認できた（例: `105894566299420`）。

推測:

- ホームには他にも「人気選手」「Tier変動」「開催中パック」等のセクションがある（下スクロールで見える範囲外）。

## 4. 選手一覧画面（プレイヤー）

事実:

- 見出し「Players」。
- 検索ボックス「選手を検索...」。入力すると結果が絞り込まれ、適用中の語が **削除可能なチップ**（例: `"messi" ×`）で表示。
- 総件数を明示（「47,479 人の選手」「59 人の選手」）。
- フィルターは横並びのドロップダウン群（画面幅を超えた分は右へスクロール）:
  **プレイヤータイプ / 状態 / ポジション / プレースタイル / 守備プレースタイル / 能力 / スキル / 基本 / プレーヤーモデル / （さらに右に続く）**
- 選手カードのグリッド。カードは OVR・ポジション・クラブ/国旗・名前・★。
- カードクリックで選手詳細へ遷移。

推測:

- 「基本」= 身長/体重/年齢/利き足 などの範囲指定。
- 「プレーヤーモデル」= 体格モデル（腕の長さ等）での絞り込み。
- 並べ替え UI は今回の画像では未確認（OVR順・Tier順・更新日順が資料に記載）。
- ページングは番号送りか無限スクロールか未確認。

## 5. 選手詳細画面

事実（リオネル メッシのカードで確認）:

- ページ内タブ: **比較する / 私のビルド / コミュニティ構築 / ビルドを保存 / REVIEWS / POST TO FEED / 共有 / スクリーンショット / 設定**
- 左: カード画像、OVR（91）、ポジション（RWG）、カードランク（S）、国旗、クラブエンブレム、下に数値（70）。
- 身体情報: 身長 170cm / 体重 67kg / 年齢 19 / Foot 左 / 状態 B（コンディション矢印）。
- **ポジション別総合値グリッド**（サッカーのポジション図の形）:
  - LWG 91 / CF 87 / RWG 91
  - ST 91
  - OMF 90 / CMF 83 / RMF 90
  - DMF 72
  - LSB 80 / CB 65 / RSB 80
  - GK 41
  - 緑色 = 適性が高いポジション。
- プレースタイル: **チャンスメイカー**。ボタン「チャンスメイカー」「ポジションブースター」。
- **監督を選択**（`監督を選択` + 数値 70）→ 監督を選ぶと相性値が変化する仕組み。
- ブースター選択: ドロップダウン2つ（例「ボールキャリー +5」「Booster 2」）+ 中央に E アイコン2つ。
- **育成パネル**（左下）:
  - ポジション指定（RWG）/ 「最大」「スマート」切替 / 歯車（設定）/ 矢印
  - レベル上限 34 / ポイント 0 / 66
  - カテゴリ別スライダー: 撮影 / パス / ドリブル / クイックネス / 脚力 / エアバトル / ディフェンス / GK1 / GK2 / GK3
- **能力値（3カテゴリ）** — 数値 + 色（緑=高、オレンジ=中、赤=低）、ブースター上昇分は緑背景で「+5」表示:
  - 攻撃: オフェンスセンス 79 / ボールコントロール 86 / ドリブル (+5) 88 / ボールキープ (+5) 85 / グラウンダーパス 81 / フライパス 76 / 決定力 80 / ヘッダー 50 / プレースキック 67 / カーブ 81
  - ディフェンス: ディフェンスセンス 47 / 守備意識 48 / 取り組む 46 / アグレッシブネス 50 / ゴールキーピング 40 / キャッチング 40 / クリアリング 40 / コラプシング 40 / ディフレクティング 40
  - 身体能力: スピード (+5) 83 / 瞬発力 87 / キック力 78 / ジャンプ 52 / 肉体的 71 / ボディバランス (+5) 86 / スタミナ 74
- **スキル**: ミドルシュート / スルーパス / ダブルタッチ / 足裏コントロール / コントロールカーブ / ワンタッチ… / モメンタム…（`SKILL FX` トグルあり）
- **プレーヤーモデル**: 腕の長さ 5 / 肩幅 9 / 首の長さ 6 / …（体格の数値）
- **物理**: 脚カバー半径 162.0 / 腕カバー半径 152.8 / …
- 「Rate this player」= 星評価。
- 広告枠あり。

推測:

- 「撮影」= シュート系能力（training の日本語表記のブレ）。「取り組む」= ボール奪取。
- 育成ポイント上限（66）とレベル上限（34）はカード種別で変わる可能性。
- ポジション別総合値・監督相性値は eFHUB 側の計算結果。自前で再現するには計算ルールの解明が必要（今回の動作版では扱わない）。

## 6. 選手比較画面

事実:

- 見出し「Compare Players」。右上「+ Add Player」。
- 左右に「ADD PLAYER / Click to search」の空枠、中央に基準選手枠。→ 最大3選手を並べる。
- 中央上に六角形レーダーチャート。軸ラベル: **SHT / SPD / PAS / DRI / PHY / DEF**（シュート/スピード/パス/ドリブル/フィジカル/守備）。
- 下に全能力値を1項目ずつ左右に数値表示（オフェンスセンス / ボールコントロール / ドリブル / ボールキープ / グラウンダーパス / フライパス / 決定力 / ヘッダー / セットプレー / カーブ / ディフェンスセンス / ボール奪取 / 守備意識 / アグレッシブネス / GKセンス / キャッチング / クリアリング / コラプシング / ディフレクティング / スピード / …）。
- 選手未選択時は全項目 40（初期値）表示。

## 7. マネージャー一覧画面

事実:

- 見出し「マネージャー」。検索「探す...」、フィルタボタン、右に総数「1804 managers」。
- 監督カード: 顔写真、日本語名、付与ブースター2種のタグ（例「ディフェンスセンス +1」「キック力 +1」「グラウンダーパス +1」「守備意識 +1」）。

  **ポゼッション / ロングカウンター / ショートカウンター / ロングボール / サイドアタック / Overload**

事実:

- 見出し「ティアリスト」。右上「マイリスト」。
- 「ティアリストを作成」カード（選手を選んで S/A/B… にランク付け）。
- プリセットのティアリスト一覧。各カードに: タイトル、3枚のカードサムネ + 「+N」、「N 選手」「M 提出」。
  - eFootball 2027（12選手 / 6,957 提出）
  - Legends Assemble Spl.（11選手 / 14,816 提出）
  - Epics & Showtime - World Cup Edition（68選手 / 12,518 提出）
  - Cristiano Ronaldo（23選手 / 4,224 提出）
  - National Team Pack England 2026（11選手 / 488 提出）
  - Season's Best (Updated)（16選手 / 3,839 提出）

推測:

- 「提出」= そのティアリストへのユーザー回答/投票の件数。

## 9. コミュニティ画面

事実:

- コメントの縦リスト。各コメント: アバター、ユーザー名（匿名可: `Anonymous`）、相対時刻（`9h ago`、`8月20日`）、種別タグ `COMMENT`、本文（英語投稿が多い）、右に添付カード画像。
- 下部: コメント数アイコン + 数値、いいねアイコン + 数値（+268 / +419 / +196 / +1586）、`Translate`（翻訳）、低評価アイコン。

## 10. スカッドビルダー画面（モバイル/タブレット）

事実:

- 見出し「SQUAD BUILDER」。左上に「＜」（戻る）と検索アイコン。
- 中央にサッカーピッチ。フォーメーション上に選手枠を配置（見えるのは GK / LB / CB / CB / RB / DMF / CMF / CMF / LWF / CF / RWF = 4-3-3 系）。各枠に OVR（87）と「C」マーカー。
- 左パネル: 監督「Luis A. Roman」、チームスタイル「Possession Game」（赤字）、「Team Strength 0」、エンブレム + 数値「36」。
- 右側: 控え/リザーブの選手カード列（7枚、すべて 87 RWF）。
- 右下: 青い丸いメニューボタン（三本線）。

推測:

- 「C」= ポジション適性やキャプテン等の状態表示。
- 「36」= チームスタイル一致度やケミストリー的な指標。
- Team Strength は配置選手から自動計算。

## 11. UI 実装への反映方針（最初の動作版）

| 要素 | 反映 |
|---|---|
| 配色 | 背景ほぼ黒（`#0b0f12` 系）、アクセントにライムグリーン（`#c7f000` 系）、テキストは淡いグレー |
| レイアウト | モバイルファースト。上部固定ヘッダー + 左からスライドインするサイドメニュー |
| ナビ項目 | ホーム / プレイヤー（実装）、マネージャー・ティアリスト・コミュニティ・スカッド（メニューに項目だけ用意し「準備中」表示、空ページを完成扱いにしない） |
| 一覧 | カードのグリッド（モバイル2列、PC 4〜6列）。上部に検索バー + 並べ替え。総件数とデータソース・取得日時を表示 |
| カード | OVR（左上・大）、ポジション、名前（日本語・英語）、選手ID |
| 検索 | 日本語名・英語名の部分一致（大文字小文字を無視） |
| 並べ替え | OVR 降順 / 昇順、名前順 |
| 詳細 | 名前（日/英）、OVR、選手ID、（あれば）ポジション。データソース・取得日時。能力値/育成/比較は「今回の動作版では未実装」と明記 |
| 状態表示 | ローディング（スケルトン）/ データなし / エラー を専用部品で共通化 |
