# 進行中マイルストーン（中断・再開文書）

使用量不足・作業継続困難で**未完了のまま安全に中断**したマイルストーンの記録を置く場所。

- ファイル名: `<feature-name>.md`
- テンプレートと手順: `docs/milestone-workflow.md` §5

中断時のルール（`docs/milestone-workflow.md` §5）:

- 品質確認を省略して完成扱いにしない
- 変更を勝手に巻き戻さない・未検証の変更を完成扱いにしない
- 総合判定は「条件付き完了」または「未完了」
- 再開手順とサーバー状態と保護状態を必ず記録する

再開が完了したら、対応する完了報告を `docs/milestones/YYYY-MM-DD-<feature>.md` へ作成し、
このディレクトリの中断文書は削除せず「完了・<日付>」と追記して残す（履歴として保持）。

現在、進行中の中断マイルストーンはありません。
