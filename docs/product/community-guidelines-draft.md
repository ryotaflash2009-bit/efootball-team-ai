## 1. 投稿のルール（利用者向けの文案）

してはいけないこと:
1. 本名・住所・学校・電話番号・メールアドレス・SNS のアカウントなど、自分や他人を特定できる情報を書く・写す。
2. 他人へのいやがらせ・差別・脅し・なりすまし（運営・公式・KONAMI を名乗ることを含む）。
3. 性的・暴力的な画像、未成年に不適切な内容。
4. 他人が作った画像・文章・データの無断の転載（スクリーンショットは自分のゲーム画面に限る）。
5. 宣伝・スパム・同じ内容の連投・アカウントの売買・不正な取引の誘い。

お願い:
- 写真を投稿する前に、写り込んだ個人情報（通知・名前・背景）を確認する。
- 位置情報は投稿時に自動で取り除く（端末で再エンコード）。

## 2. 公開範囲（段階）

| 段階 | 誰が見られるか | 条件 |
|---|---|---|
| 2 | 本人だけ | Storage・RLS の本人の分離を確認済み（CI 7/7）・本人の承認で適用 |
| 3 | URL を知っている人 | 通報・ブロック・管理者の非表示・監査ログが本番で動いている |
| 4 | 承認した友達 | 友達の双方向の承認・解除とブロックで即時に見えなくなる |
| 5 | 全体 | 段階 3・4 の運用の実績・本人の判断 |

既定は非公開。年齢は聞かない（規約に年齢の条件を書くかは法務の判断）。

## 3. 通報の運用

- 受付: 投稿ごとの「通報」（理由: 個人情報・なりすまし・嫌がらせ・不適切な画像・スパム・その他、任意のメモ 500 文字）。
- **自動で削除しない。** 個人情報・未成年の安全に関わる通報、または同じ投稿への通報が一定数を超えたものは、管理者の確認まで一時的に非表示。
- 確認の目安: 48 時間以内（招待ベータの間は本人だけが管理者）。個人情報・未成年の安全は最優先。
- 結果: 非表示の継続 / 再表示 / 投稿者へ削除の依頼。投稿者へは理由の種類だけを伝え、通報者は伝えない。
- 記録: 管理者の操作は監査ログ（誰が・いつ・何を・理由）。本文・画像は監査ログに残さない。
- 異議: 投稿者は 1 回だけ再確認を依頼できる。

## 4. ブロック・ミュート

- ブロック: 互いの投稿・プロフィールが見えなくなる。相手に通知しない。
- ミュート: 自分の画面だけで相手を表示しない。

## 5. データの保持（案）

| データ | 保持 |
|---|---|
| 投稿・画像 | 本人が削除するまで。削除で行と画像を消す |
| 監査ログ | 1 年（案）。本文・画像なし |
| 通報 | 解決から 1 年（案） |
| 退会 | 投稿・画像・ブロック・ミュートを消す。監査ログは利用者 ID だけ残す（案） |

## 6. 本人・法務の判断が必要な点

1. 年齢の条件を規約に書くか（13 歳未満の扱い）。
2. 保持期間（§5）。
3. 通報の確認の目安（48 時間）を規約に書くか。
4. 外部（警察・保護者）への連絡が必要な場合の方針。
