## 規則（実装済みの契約）

| 項目 | 規則 |
|---|---|
| 通報の対象 | 投稿・写真・コメント・プロフィール |
| 理由 | 個人情報・未成年の安全・連絡先・正確な位置・なりすまし・嫌がらせ・不適切な画像・スパム・著作権・その他（メモは 500 文字まで） |
| 一時的な非表示 | 緊急の理由（個人情報・未成年・連絡先・位置）は 1 件で・それ以外は別々の通報者 3 人で。**自動で削除しない** |
| 悪意のある通報 | 同じ人の同じ理由は 1 件として数える・1 人 1 時間 5 件まで・自分の投稿は通報できない |
| 判断 | 非表示の継続 / 再表示 / 投稿者へ削除の依頼。再表示の後に新しい緊急の通報が来たら再び一時的に非表示 |
| 異議 | 投稿者が 1 件の事案に 1 回だけ |
| 伝える内容 | 投稿者へは状態と理由の種類だけ（通報者は伝えない） |
| 監査ログ | 誰が（system / admin / owner）・いつ・何を・理由の種類・結果。**本文・画像・メモは残さない** |
| ブロック・ミュート | ブロックは両方向で見えない（公開 ID の提案の RLS で確認済み）・ミュートは自分の画面だけ |
| 管理者の認証 | 管理の操作は再認証つき・管理者の役割は通常の利用者と分ける（Auth の公開の前に実装） |

## 保証しないこと（利用者向けの文に書く）

24 時間以内の対応・即時の削除・法的な判断・専門のモデレーション・緊急の通報先（警察・救急）の代わり。
