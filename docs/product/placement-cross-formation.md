# 違うフォーメーション間の配置の写し（NEW-41・2026-10-07）

F-036 の「配置をコピー／貼り付け」を、違うフォーメーションのスカッドへも使えるようにした。
同じフォーメーションの間は今まで通り（座標とロールの上書きをそのまま写す）。

## 枠の対応の規則（決定的・推測なし）

1. 対応は同じ役割の区分（GK / DF / MF / FW）の中だけ。区分をまたいで対応させない。
2. 区分の中では、両方のフォーメーションの**既定の座標**の距離の二乗の合計が最小になる 1 対 1 の組み合わせを選ぶ。
   同じ値の場合は枠の ID の辞書順で最初の組み合わせ（`mapFormationSlots`・全 10×10 の組み合わせをテスト）。
3. 区分の人数が違う場合、多い側の残りの枠は対応なし（貼り付け先では今のまま）。

## 写すもの

- 対応した枠ごとに「元の座標 − 元の既定の座標」（既定の位置からのずれ）を、貼り付け先の枠の既定の座標に足す（0〜100 に収める）。
  貼り付け先のフォーメーションの形を保ったまま、前に出す・幅を取るなどの調整だけが写る。
- 配置ロールの上書きは写さない（ポジションが違うと意味が変わるため）。
- フォーメーション・選手・ビルド・ブースター・キャプテン・セットプレー・ベンチ・監督は変えない。
- 元に戻すで 1 操作として戻せる。案内に対応した枠の数と対応なしの枠の数を出す。
