# F-034 人間工学・認知工学監査（2026-09-27）

対象: World 選手詳細の育成タブ（能力値直接操作・スライド式育成UI）。
方法:
- 実装の読み直しと、各 viewport のスクリーンショットによる専門家評価（Nielsen の10原則、Fitts・Hick・Jakob の法則、近接・一貫性）。
- 初回利用者シナリオ A〜F、誤操作、片手操作、タッチ操作の自動 black-box（`scripts/black-box-ability-progression.mjs`、全8 viewport）。
- 実機の iPhone は操作できないため、390×844・393×852・430×932 のタッチイベント（CDP）で代替した。体感（触り心地・発光の好み）は本人の主観確認に残す。

時間の計測は自動操作の所要時間であり、人の反応時間ではない。そのため、操作数と画面移動量（px）を主な指標にした。

## 1. Severity の基準

0 = 問題なし、1 = 見た目、2 = 軽微、3 = 重大（次の機能の前に必ず直す）、4 = リリース不可。

## 3. 問題なしと判断したもの（Sev 0）

- **操作の対応:** スライダーは右で増・左で減。＋は増・−は減。スライダー・＋／−・キー操作・チップはすべて同じ状態を通る（単体テストで同値を確認）。
- **縦スクロールの誤作動:** スライダー上から縦にスクロールしても値は変わらない（`touch-action: pan-y` と pointercancel での取り消し）。
- **追従:** 小さな／速い／ゆっくりの／斜めのドラッグ、指がトラックから外れた場合のすべてで、指の横位置どおりのレベルになる。取り消されたタッチは元に戻る。
- **ポイント不足・カテゴリ上限:** 超えられない。理由は文言と斜線で示す（色だけに頼らない）。
- **視覚の優先順位:** 選択中（強い発光＋「選択中」）、関連（◆＋枠）、無関係（不透明度 0.62・読める・押せる）。
  - 能力値は数値バッジで常に読め、発光は枠の外側だけで数値には重ならない。
  - ポイント不足は警告色と ⚠ で示し、赤一色の全面表示はしない。
  - 動きは 100〜220ms で、動きを減らす設定では止まる。
