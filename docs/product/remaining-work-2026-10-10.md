## §2 同じ選手の別のカードの規則（2026-10-10 の確認の結果と提案）

ゲームの規則（本人の確認）: 同じ選手の別のカードは同じスカッドに入れられない。TeamAIXI の今の状態:

| 所 | 今の扱い | ゲームの規則との差 |
|---|---|---|
| スカッドの編集（`src/lib/squad/assign.ts`） | 同じカード ID だけ拒否。**同じ選手の別のカードは許可**（コメントで明記） | 食い違う（入れられないスカッドを作れる） |
| 保存データの読み込み・正規化（`squad-storage.ts`）・インポート | 同じカード ID だけ除く | 食い違う（ただし既存の保存データを消してはいけない） |
| AI ベスト11 | 同じ名前のカードを「知らせる」だけ（#219） | 食い違う（2 枚を選ぶことがある） |
| 改善のシミュレーション・フォーメーションの変更 | スカッドの中の選手の入れ替え・移動だけ（新しい重複は作らない） | 元のスカッドに重複があればそのまま |
| 診断 | 重複を見ていない | 重複のあるスカッドをそのまま評価する |

**問題（不具合として扱う）**: 「同じ選手」を決める ID がデータに無い（World は カード ID だけ）。同じ英語名のカードは 2,153 名・11,424 枚あり、
名前が同じでも別の選手（国籍が違う: Luis Suárez・Pedro・Paulinho・Otávio・Pedrinho・Alan など少なくとも 7 名）もいる。名前だけでは誤判定する。

**提案（本人の判断の後に実装・推測での自動の削除はしない）**:
1. 「同じ選手」の判定 = 英語名（NFKC・大文字小文字・空白をそろえる）＋ 国籍 が同じ。外れ（同名・同国籍の別人）がありうる旨を画面に出す。
2. スカッドの編集: 同じ選手がいるときは追加を止め、理由を表示（入れ替えの導線つき）。
3. AI ベスト11: 同じ選手の 2 枚目以降は選ばない（評価の高い 1 枚を残す）。控えも同じ。
4. 診断・改善のシミュレーション: 重複があれば「ゲームでは編成できない」と知らせる（点数の計算は変えない）。
5. 保存データの復元・インポート: **消さない・変えない**。読み込んだ後に重複を知らせ、本人が外す。
6. テスト: 判定の単体テスト・同名の別人（国籍違い）を同じ選手と見なさない・既存の保存データが変わらない・black-box（スカッドの編集・AI ベスト11）。

本人に決めてほしいこと: (a) 判定の方法（英語名＋国籍でよいか）、(b) 上の 2〜5 を一貫して適用してよいか。
