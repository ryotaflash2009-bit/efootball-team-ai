## 2. 監督データ・監督画像

| 項目 | 確認結果 |
|---|---|
| 調査記録 | `docs/manager-image-sources.md`に、6つの候補サイト(eFootball DB、eFootBase、EFScout、eFootBox、amine250、KONAMI公式)を調査した記録が存在する(3回の調査・累計44外部リクエスト)。 |
| 結論(既存記録) | 「eFootball 監督画像 = KONAMI のゲームアセット、ファンサイトに再配布許諾なし」と明記。6サイトすべてが再配布許諾なしと判定されている(判定C/D/Eのいずれか、Aと判定されたサイトは0件)。 |
| KONAMI公式の扱い | 監督データベース・監督個別画像自体が存在せず、掲載されているライセンス表記はサッカー連盟(RFEF/KNVB)等の楽曲・団体ライセンスのみ。ゲームアセット自体はKONAMIのEULA管理下で商用再配布不可と記載されている。 |
| 現行実装での対応 | **監督画像は一切表示せず、イニシャルアバターのみを使用する設計になっている**ことをコード・ブラックボックステスト双方で確認した(`black-box-manager-picker.mjs`の「監督一覧: 画像を架空生成しない(imgタグを監督カードに使わない)」等)。既存の判断は、この調査結果を踏まえた適切な対応であると評価できる。 |
| 監督の能力値・戦術データ自体 | 画像とは別に、監督のテキストデータ(戦術適性・ブースター等)がSQLiteに格納されているが、これらの取得元・再配布条件についての個別調査記録は本書の調査範囲では確認できなかった(0章のとおり停止条件としては扱わない)。 |
