# 月額運用費概算(3段階)

調査日: 2026-09-11。価格は各社公式サイト・第三者解説記事(2026年時点)に基づく概算であり、**確約された金額ではない**。契約前に必ず公式サイトで再確認すること。前提構成は`decision-record.md`の第一推奨(Vercel + Supabase)。

## A. 身内テスト(5人程度・低アクセス)

| 費目 | 想定プラン | 概算月額 |
|---|---|---|
| ホスティング(Vercel) | Hobby(無料。ただし個人・非商用限定という利用条件に注意) | **$0** |
| 認証(Supabase Auth) | Free(50,000 MAUまで無料) | **$0**(5人なら無料枠内) |
| DB(Supabase Postgres) | Free(500 MB、2プロジェクトまで) | **$0** |
| ストレージ | Supabase Free内(1 GB) | **$0** |
| 帯域 | Vercel Hobby内(100 GB/月) | **$0** |
| 画像配信 | 既存の自前プロキシ(追加費用なし) | **$0** |
| メール(認証確認メール等) | Supabase標準のメール送信機能(無料枠内の送信数制限あり) | **$0**(低頻度なら収まる可能性が高いが、契約時に送信数上限を要確認) |
| 監視 | 未契約 | **$0** |
| バックアップ | 未契約(Freeプランには自動バックアップなし) | **$0**(ただしデータ消失リスクは自己負担) |
| ドメイン | 独自ドメイン未取得(Vercel既定の`*.vercel.app`ドメインを使用) | **$0** |
| その他 | - | - |
| **合計目安** | | **概ね$0/月** |

**注意**: Vercel Hobbyプランは「個人・非商用プロジェクト」向けであり、身内であっても実質的な運用形態次第では利用条件に抵触する可能性がある(契約時に規約を確認すること)。またSupabase Freeプランは**7日間操作がないとプロジェクトが自動停止する**ため、身内テストであっても定期的なアクセスがないと停止する点に注意。

## B. 招待制ベータ(50〜100人程度)

| 費目 | 想定プラン | 概算月額 |
|---|---|---|
| ホスティング(Vercel) | **Proプランへ移行を推奨**($20/開発者・月〜、商用利用・帯域拡張のため) | **約$20〜** |
| 認証(Supabase Auth) | Free継続でも収まる可能性が高い(50,000 MAU上限に対し100人は十分小さい) | **$0** |
| DB(Supabase Postgres) | **Proプランへ移行を推奨**($25/月〜。500 MBのFree枠は100人規模のMy Team・保存ビルドデータで超過する可能性があるため) | **約$25〜** |
| ストレージ | Supabase Pro内に含まれる分で当面収まる見込み | 含まれる |
| 帯域 | Vercel Pro内(1 TB/月)で当面収まる見込み | 含まれる |
| 画像配信 | 自前プロキシ継続 | **$0** |
| メール | Supabase Pro内の送信数拡張、または不足時に別途メール送信サービス検討 | **$0〜数ドル**(要個別確認) |
| 監視(Sentry) | Developer無料枠(5,000イベント/月)を試行、規模次第でTeam $26〜/月を検討 | **$0〜$26** |
| バックアップ | Supabase Proに日次バックアップが含まれる | Proプラン費用に含む |
| ドメイン | 独自ドメインを取得する場合、レジストラにより年額$10〜$20程度(月割り概算$1〜$2) | **約$1〜$2** |
| その他 | - | - |
| **合計目安** | | **概ね$46〜$75/月程度**(ドメイン取得・監視有料化の有無で変動) |

## C. 一般ベータ(1,000人程度)

| 費目 | 想定プラン | 概算月額 |
|---|---|---|
| ホスティング(Vercel) | Pro継続、使用量次第でオーバー分の従量課金が発生 | **$20〜(使用量次第で増加)** |
| 認証(Supabase Auth) | 1,000人はFree枠(50,000 MAU)に対して依然小さいが、他の理由でPro契約済みなら同一プラン内 | **$0(単体では)** |
| DB(Supabase Postgres) | Proプラン継続、データ量次第でストレージ従量課金が上乗せされる可能性 | **$25〜(使用量次第で増加)** |
| 帯域 | 1,000人規模だとVercel Proの1TB枠を超える可能性があり、超過分$0.15/GB | **変動(要監視)** |
| メール | 送信数増加に伴い専用メール送信サービス(SendGrid等)の検討が必要になる可能性 | **要個別見積り** |
| 監視(Sentry) | Teamプラン相当($26〜$29/月)が現実的 | **約$26〜$29** |
| バックアップ | Supabase Pro継続 | Proプラン費用に含む |
| ドメイン | 継続 | **約$1〜$2** |
| その他 | 帯域・DB使用量超過分の従量課金バッファ | **要監視・要予算確保** |
| **合計目安** | | **概ね$75〜$150/月程度、利用状況次第でさらに変動** |

## 無料枠超過条件のまとめ

| サービス | 無料枠 | 超過時の課金開始条件 |
|---|---|---|
| Vercel Hobby | 100時間Function実行/月、100 GB帯域/月 | いずれか超過でProプラン移行が必要(または機能制限) |
| Supabase Free | 500 MB DB、50,000 MAU、2プロジェクトまで、**7日間無操作で自動停止** | DB容量超過またはプロジェクト常時稼働が必要になった時点でPro移行 |
| Neon Free(代替構成時) | 0.5 GB storage、100 CU時間/月 | 超過時は従量課金(Launch $0.106/CU時間〜) |
| Clerk Free(代替構成時) | 50,000 MRU | 超過時はProプラン($20/月〜) |
| Sentry Developer | 5,000イベント/月、1ユーザー | 超過時はTeamプラン($26〜$29/月) |
| GitHub Actions(将来CI/CD導入時) | プライベートリポジトリ2,000分/月(パブリックリポジトリは無制限) | 超過時は$0.006/分〜(2026年1月改定後) |

## 確認できなかった/断定を避けた価格

- Supabase・Vercel・Neonいずれも「実際の使用量に応じた従量課金」の最終的な月額は、利用者数・アクセスパターン・データ量に強く依存するため、**本書の数字はあくまで概算レンジ**である。
- メール送信サービス(招待制ベータ以降で必要になる可能性)の具体的な費用は未調査(必要になった段階で個別調査する)。
